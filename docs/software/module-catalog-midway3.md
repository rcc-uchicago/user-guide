# Midway3 Software Module Catalog

This page lists the software modules available on Midway3 (`module avail` from `/software/modulefiles`), grouped by category. The list was last updated on <!-- MODULE_CATALOG_DATE -->, so `module avail` on the cluster is always the authoritative source. For Midway2, see the [Midway2 Software Module Catalog](module-catalog-midway2.md).

To load a module, use `module load <module>/<version>`, for example `module load lammps/29Aug2024`. If you omit the version, the default version (shown in **bold**) is loaded. See [Shared Software](index.md#shared-software) for more on the `module` command.

!!! note "Modules for AMD CPUs"
    The modules for the `amd` partitions are not included in this list. To see them, run `module use /software/modulefiles-amd` and then `module avail`.
