# Midway2 Software Module Catalog

This page lists the software modules available on Midway2 (`module avail`), grouped by category. The list was last updated on <!-- MODULE_CATALOG_DATE -->, so `module avail` on the cluster is always the authoritative source. For Midway3, see the [Midway3 Software Module Catalog](module-catalog-midway3.md).

To load a module, use `module load <module>/<version>`. If you omit the version, the default version (shown in **bold**) is loaded. See [Shared Software](index.md#shared-software) for more on the `module` command.
